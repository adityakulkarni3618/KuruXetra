# KURUXETRA SPORTS MANAGEMENT SYSTEM (KSMS) - PROJECT DIGEST
===========================================================

## Project Stack
- **Backend**: Node.js, Express, TypeScript, PostgreSQL, Prisma, JWT authentication.
- **Frontend**: Next.js 15 (App Router), TypeScript, Tailwind CSS, Recharts.

---

## Directory Structure
- `/backend`:
  - `src/`: Express & TypeScript application code.
  - `prisma/`: Prisma schema and database seeds.
    - `schema.prisma`: Core database models (User, Season, Sport, Membership, Attendance, Workout, RunningLog, PointsLedger).
    - `seed.ts`: Seeds the initial Super Admin (`ss_admin` / `Admin@123`) and demo sports.
  - `package.json`: Backend npm scripts (`dev`, `build`, `start`, `prisma:generate`, `prisma:migrate`, `prisma:seed`).
- `/frontend`:
  - `app/`: Next.js App Router (pages: login, registration, dashboard, etc.).
  - `components/`: UI components.
  - `lib/`: Shared logic, auth context, API client wrapper.
  - `package.json`: Frontend npm scripts (`dev`, `build`, `start`, `lint`).

---

## Core Database Schema (Prisma)
- **Role Enum**: `SUPER_ADMIN`, `CAPTAIN`, `STUDENT_ATHLETE`, `FITNESS_MEMBER`
- **UserStatus Enum**: `PENDING_APPROVAL`, `ACTIVE`, `SUSPENDED`
- **MembershipStatus Enum**: `PENDING`, `APPROVED`, `REJECTED`, `REMOVED`
- **Models**:
  - `Season`: Tracks sports seasons (e.g., "2026-27") for auditing and segregation of records.
  - `User`: Handles registration, roll number, college ID, role, status, credentials.
  - `Sport`: Holds sport details (practice time, captain ID, max members, status).
  - `Membership`: Maps User to a Sport with a MembershipStatus.
  - `Attendance`: Logs check-in/out times, duration, and whether it was marked by a captain or self-checked.
  - `Workout`: Logs general exercises, sets, reps, weight, calories, duration.
  - `RunningLog`: Logs distance, duration, auto-calculated pace/speed, and calories.
  - `PointsLedger`: Append-only points ledger tracking how points are awarded (e.g., via attendance, workouts, running logs).

## Key Terminal Commands

### Database Startup (Docker)
```bash
docker run --name ksms-db -e POSTGRES_USER=ksms_user -e POSTGRES_PASSWORD=ksms_pass -e POSTGRES_DB=ksms -p 5432:5432 -d postgres:16
```

### Backend Setup & Running
```bash
cd backend
cp .env.example .env     # Then edit .env with your DATABASE_URL and JWT_SECRET
npm install
npx prisma generate
npx prisma migrate dev --name init
npx prisma db seed
npm run dev              # Starts backend on http://localhost:4000
```

### Frontend Setup & Running
```bash
cd frontend
npm install
echo "NEXT_PUBLIC_API_URL=http://localhost:4000" > .env.local
npm run dev              # Starts frontend on http://localhost:3000
```
